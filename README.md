# Vibe-coded vs. Engineered

**https://rexmhall09.github.io/todo-list-experiment/**

Gemma 4 E2B, running locally in TUFF, builds the same to-do app from two prompts: a [one-paragraph request](prompts/vibe-coded.md) and a [full specification](prompts/agentic.md). One prompt each, no follow-ups. Each app is the best of 8 runs of its prompt, scored by the same [behaviour tests](tests/index.html). Every line of app code was written by the model.
